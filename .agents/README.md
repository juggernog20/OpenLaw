# Agent guidance

Instructions and inventories for the coding agents that work on this repository. Product and contributor documentation lives in `docs/` and `README.md`, not here.

- `CLAUDE.md`: the entry point. The root `CLAUDE.md` imports it.
- `domain.md`, `issue-tracker.md`, `triage-labels.md`: how agents use the glossary, the issue tracker and the triage labels.
- `unslop-comments.md`: the inventory the comment-review sweep reads.
