# Read and download Documents

Open the right Document Version, read supported formats in place, and download the original when you need it outside OpenLaw.

## Before you start

Staff readers need access to the owning record and the Document. Business Users read permitted Contract and Matter paper, their Request thread attachments and published Knowledge through the Portal; the portal does not grant access to the staff Documents repository or a Contract's full Version history.

## Read a managed Document

1. Open the owning record's **Documents** tab or the Documents section on a Knowledge Item. Select the Document name. A download-only format downloads directly from this row.
2. Check the title and **v…** indicator in the reader. Expand the Document row and select an earlier filename when you need a previous Version.
3. For PDF-based previews, use **Previous page**, **Next page**, **Zoom out**, **Zoom in**, and **Find in document**. Find uses available text; an image-only scan may have no selectable or findable text in its displayed pages.
4. Select **Download** for that Version's original file. Use **Close the document** to return to the record.

The original Word or PowerPoint download remains the uploaded file, even though the preview is a converted PDF. A preview is not a new Version. For changes between rounds, use [Document Comparison](compare-versions.md).

## Supported reading surfaces

| File                                                   | What to expect                                                                                                                                       |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| PDF                                                    | The original pages; image-only scans remain scans in the reader.                                                                                     |
| Word and PowerPoint formats supported by the converter | A PDF rendition after preparation. Word tracked changes and comments are rendered for reading; download the original to work with the editable file. |
| Supported raster images, including PNG and JPEG        | An inline image.                                                                                                                                     |
| EML or MSG email                                       | Message headers, body, and an attachment list. Remote images and active content are not loaded in the message body.                                  |
| Other formats, including spreadsheets, ZIP, and SVG    | The name downloads the file directly. If opened through a reader link, a download-only card explains that the type does not open here.               |

For an email attachment, use its download action. PDF and supported image attachments can open in a preview; a Word attachment inside an email downloads rather than starting a separate conversion. Reading an email does not turn its attachments into separately managed Documents.

## Processing, scans, and failed previews

**Preparing this document for reading…** means conversion is still pending. Leave the reader open or return later. The upload can already be stored and downloadable while conversion or text extraction is unfinished.

Image-only PDFs are OCR'd in the background for text search. OCR does not replace the original scan or guarantee a perfect transcription. Use [global search](search-and-views.md) to find indexed text after processing; the PDF reader's Find control searches the text available in the displayed PDF.

If **This file could not be prepared for reading here. Download it to read it.** appears, try **Download** and open the original in a suitable application. Reopening the same Version is not an explicit processing retry. If the file itself is damaged, obtain a readable copy and [add a Version](document-versions.md); earlier Versions remain in the chain. If valid files keep failing or processing never finishes, give your Administrator the owning record, Document, Version number, and visible symptom for [deployment troubleshooting](operator-troubleshooting.md).

A failed original download is different from a failed preview. Reopen the record to check your session and access. A Document may have been archived or deleted, or its stored file may be unavailable. Ask Legal or your Administrator to investigate; uploading another copy does not restore the missing bytes of an earlier Version.

## Read files in the Business Portal

On your own Request thread, select a Request or comment attachment to download it. Only files within that thread's permitted audience are available. Follow [Request updates](follow-request.md) for supplying another file; an attachment is not a Version-history control.

Open [Knowledge shared with the business](portal-knowledge.md) for published guidance. Its primary Document is listed first when available. Use **Download** beside a listed file to read its current Version outside the portal; this page has no in-app Document preview or Version-history picker. An unpublished or archived item, or an item whose audience changed, may no longer be available. Ask Legal about the missing material rather than trying the staff record's address.
