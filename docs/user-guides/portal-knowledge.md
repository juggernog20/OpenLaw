# Read Knowledge shared with the business

Read your organization's guidance and download supporting Documents from the Portal before sending a Request to Legal.

## Before you start

[Sign in to the Portal](portal-sign-in.md). Legal must have published the Knowledge Item for **Everyone** and kept it available. Everyone still requires a signed-in Portal session; it does not make the item an anonymous public page.

Organization Knowledge explains your organization's policies or work. **Help** explains how to use OpenLaw. Searching product Help does not search organization Knowledge or Requests.

## Open guidance and Documents

1. On the Portal home or a request form, look under **Before you submit**. The available links can differ between the home page and individual forms.
2. Open the guidance you need before filling in the form. A Knowledge link opens in the same tab; do not rely on unfinished form answers being kept when you leave it.
3. Check the title under **From Legal**.
4. Under **Documents**, select **Download** beside the file you need. If Legal chose a primary Document, it appears first; download any supporting files you also need. The Portal supplies each Document's current Version, without a version-history picker or embedded Document reader.
5. Read **Guidance** if the item includes written instructions.
6. Select **Your requests** to return to the Portal home. Choose the request type again if you still need to [submit a Request](submit-request.md).

An item may contain Documents, written guidance, or both. The Portal does not offer the staff Knowledge library or its editing controls. Use the configured links or a Portal Knowledge link Legal shares with you.

## External links and unavailable guidance

An external link shows its website beneath the label and opens in a new tab. If that website is unavailable, return to the original Portal tab to continue the form. Tell Legal which link failed; a broken external website does not prevent submitting the Request.

If an internal Knowledge link returns you to the Portal home, the item may no longer be available to you. Draft, restricted, archived, and unknown items do not open in the Portal. Ask Legal for current guidance. The same access check applies to the item's files, including a download address saved earlier.

If a Document will not download, reload the item and try its current **Download** link. Legal may have changed or removed the Document or the item's availability. A file previously downloaded to your computer does not update automatically when Legal publishes a new Version; download it again when you need the current file.
